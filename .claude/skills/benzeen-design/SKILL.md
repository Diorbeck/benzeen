# Benzeen Design Doctrine — Uber-restraint

Benzeen привозит топливо к машине клиента в Ташкенте, 24/7. Референс —
uber.com: утилитарная сдержанность, форма-первый интерфейс, почти монохром.
**Принцип: незаметность = качество.** Дизайн хорош, когда его не замечают —
замечают, что заказ оформился за минуту.

Проверка вкуса: *каждый экран начинается с действия, а не с рассказа о себе.*
Если между пользователем и действием стоит слоган, анимация или декор —
убрать.

## 1. Форма-первый интерфейс

- Главная начинается НЕ со слогана, а с мини-виджета заказа: заголовок
  32–36px, под ним сразу поле «Куда привезти», селектор топлива и кнопка
  «Заказать» → /benzin с предзаполнением.
- Ниже — ряд карточек-сервисов (как Uber Ride/Reserve): серые заливки
  `gray-100`, без бордеров и теней, текст слева + иконка/стрелка.
- Маркетинг (как работает, FAQ) — ниже и компактно. Никогда не выше формы.

## 2. Цвет — почти монохром

| Роль | Значение | Использование |
| --- | --- | --- |
| Фон | `#FFFFFF` | страницы; секции разделяются воздухом, не заливками |
| Текст | `navy` (near-black) | основной; вторичный `gray-500/600` |
| Заливки контролов | `gray-100` | поля ввода, карточки-сервисы, secondary-кнопки |
| **Тиффани `#0ABAB5`** | `primary-500` | ТОЛЬКО главные CTA и активные состояния (выбранный чип — тиффани-БОРДЕР, не заливка) |
| Чёрный блок | `gray-900` | кнопки второго ранга (uber-чёрный); в тёмной теме инвертируется в белый |
| Success / Warning / Danger | `#059669` / `#D97706` / `red-600` | только статусы |

Запрещено: синие заливки и подложки карточек (`bg-primary-50` как фон — нет),
градиенты, glow, неон, стоковые фото, 3D. Тиффани-элементов на экране —
не больше одного смыслового фокуса.

## 3. Типографика — плотная

| Уровень | Desktop | Mobile | Вес |
| --- | --- | --- | --- |
| Заголовок страницы/hero | 32–40px | 26–30px | 700 |
| Секция | 22–26px | 20–22px | 600–700 |
| Body | 15–16px / 1.5 | — | 400 |
| Caption | 13–14px | — | 500 |

Без display-полотен (48px+ запрещены). Трекинг −0.01em на заголовках.
Иерархия весом, не цветом. Цифры — `tabular-nums`. Inter, второго шрифта нет.

## 4. Формы и кнопки — прямоугольные

- Радиусы: **8** контролы/кнопки (`rounded-control`), **12** карточки
  (`rounded-card`), **16** шиты (`rounded-sheet`). **Пилюль нет.**
- Кнопки: высота 48 (`md`), блоки — тиффани (главное действие) или
  чёрный `gray-900` (uber-стиль; в тёмной теме — белый с тёмным текстом).
  Press: scale(0.98). Никаких glow/теней на кнопках. Текст на тиффани-заливке —
  тёмный петроль `text-primary-950` (белый на #0ABAB5 не проходит контраст).
- Поля ввода: **серые заливки без рамок** — `bg-gray-100`, placeholder
  `gray-500`, focus — кольцо 2px `navy` (не тиффани: тиффани занята CTA).
  В тёмной теме `white/10`.
- Карточки: серые заливки ИЛИ белые с тонким бордером `gray-200` — теней
  почти нет (`shadow-soft` только у плавающих поверхностей: шиты, поповеры).

## 5. Тёмная тема — петроль

Не чёрно-угольная: фон `#071815`, поверхности `#0C2420` → приподнятые `#123029`,
бордеры `#1F4A43`/`white/10`. Токены `navy-950/900/800/700` хранят эти
значения — не добавляй новых классов. Текст `#F5F5F5`/`gray-400`. Тиффани на
петроле читаема — использовать `primary-400/300` для мелкого текста-акцента.
Чёрные кнопки инвертируются в белые.

## 6. Motion — почти ноль

«Незаметность = качество». Разрешено ТОЛЬКО:
- направленные переходы шагов /benzin (форк → флоу);
- шиты: вход/выход **200мс** ease-out (токен `sheet` в `src/lib/motion.ts`);
- skeleton-shimmer на загрузке;
- pulse маркера курьера на живом трекинге (статус, не декор);
- CSS hover/press 150мс.

Запрещено: hero-стаггеры, каскады появлений, fade+rise секций по скроллу,
count-up цифр, parallax, бесконечные анимации. Всё мгновенно и на месте.
`prefers-reduced-motion` убирает и разрешённое.

## 7. Компоненты — нормы

- **Чипы выбора** (топливо, объём, слоты): прямоугольники `rounded-control`,
  невыбранный — `bg-gray-100` без бордера; выбранный — тиффани-бордер
  2px + `bg-white` (тёмная: `white/10` + тиффани-бордер). Без синих заливок.
- **Инпуты**: 48px, серые заливки (см. §4), ошибки — красный текст под полем.
- **Статусы**: цвет только у точки/бейджа. Бейджи — `rounded-md`, не пилюли.
- **Иконки**: lucide, нейтральные `gray-500`/`navy`; без цветных подложек.
- **Touch ≥44px**, focus-кольца видимы, контраст ≥4.5:1.

## 8. Definition of Done дизайн-PR

1. Скриншоты: все экраны × light+dark × мобайл+десктоп.
2. next-intl uz/ru/en, длины проверены.
3. Токены из `tailwind.config.ts`/`globals.css`/`src/lib/motion.ts` — без
   инлайн-значений.
4. Тёмная тема first-class (угольная), CI зелёный, backend не тронут.
