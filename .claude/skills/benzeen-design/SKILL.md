# Benzeen Design Doctrine — Apple-минимализм

Benzeen привозит топливо к машине клиента в Ташкенте, 24/7. Референс —
apple.com: одна мысль на экран, много воздуха, крупная спокойная типографика,
ничего лишнего. **Простота, а не пустота**: убираем декор, а не смысл.

Проверка вкуса: *если элемент можно убрать и ничего не потерять — убрать.*
Никаких надзаголовков «01 / ЗАКАЗ», золотых акцентов, силуэтов и рамок ради рамок.

## 1. Структура страницы

- Hero по центру: заголовок, одна фраза пояснения, одна тиффани-кнопка-пилюля
  и вторичная ссылка с шевроном «›». Hero не анимируется (это LCP).
- Дальше — **полосы**, чередующие белый и `mist-50` (тёмная: `navy-950` /
  `navy-900`). Полосы отделяются тоном, не бордерами.
- Внутри полос — **плитки** `rounded-[28px]` без рамок и теней: на тонированной
  полосе плитка белая (тёмная `navy-800`), на белой — `mist-50` (тёмная `navy-900`).
- Заголовки секций по центру; FAQ узкой колонкой (~760px) с «+» → «×».
- Подвал — мелкий серый текст 12–13px на `mist-50`.

## 2. Цвет

| Роль | Значение | Использование |
| --- | --- | --- |
| Фон | `#FFFFFF` / тёмная `navy-950 #071815` | страница |
| Полосы | `mist-50 #F4F7F5` / тёмная `navy-900` | чередование секций |
| Плитки на полосе | белый / тёмная `navy-800` | заказ, карта, списки |
| Текст | `navy` / `white`; вторичный `gray-600` / `gray-400` | |
| **Тиффани `#0ABAB5`** | `primary-500` | только действие (кнопки-пилюли) и живые данные (точки АЗС, маршрут, бак) |
| Текстовый акцент | `primary-700/800` / тёмная `primary-300` | вторая строка hero, ссылки «›», номера шагов |
| Тёмная плитка | `navy` (светлая тема) | «Заправились — и уехали» |
| Статусы | `success/warning/red` | только точки и бейджи |

Запрещено: золото в UI (только бейдж «Демо»), градиенты, glow, стоковые фото,
3D, цветные подложки иконок.

## 3. Типографика

Golos Text для всего (Unbounded — только логотип). Иерархия весом 600 и
размером, трекинг отрицательный и растёт с кеглем.

| Уровень | Mobile | Desktop | Трекинг |
| --- | --- | --- | --- |
| Hero | 42px | 64–80px | −0.035em, leading 1.05 |
| Секция | 34px | 48px | −0.03em |
| Плитка | 26px | 30px | −0.025em |
| Лид | 17px | 21px | 0 |
| Body | 15–17px / 1.5 | | 0 |
| Подписи | 12–13px | | 0 |

Заголовки на главной — явный `font-sans` (глобальное правило h1/h2 ещё
указывает на editorial-шрифт для остальных страниц). Цифры — `tabular-nums`.

## 4. Контролы

- **Кнопки — пилюли** (`rounded-full`): главная — тиффани, h-12/14, 17px/500.
  Press `scale(0.97–0.98)`. Без теней и glow.
- **Сегмент-контрол** вместо чипов: дорожка `mist-100` `rounded-full`, белый
  «бегунок» с мягкой тенью перетекает к выбору (тёмная — `white/16`).
- **Поля**: h-14, `rounded-2xl`, `mist-50` без рамки; выбранное состояние —
  кольцо тиффани 2px.
- **Шапка**: 64px, `white/75` + `backdrop-blur-xl`, хайрлайн `black/6`.
  Поверх карты — «стекло» (`white/75` + blur) для подсказок и карточки АЗС.
- Touch ≥44px, focus-кольца видимы, контраст ≥4.5:1.

## 5. Тёмная тема — петроль

Не чёрно-угольная: фон `#071815`, поверхности `#0C2420` → приподнятые `#123029`,
бордеры `#1F4A43`/`white/10`. Токены `navy-950/900/800/700` хранят эти
значения — не добавляй новых классов. Текст `#F5F5F5`/`gray-400`. Тиффани на
петроле читаема — использовать `primary-400/300` для мелкого текста-акцента.
Чёрные кнопки инвертируются в белые.

## 6. Motion — живой, но функциональный

«Незаметность = качество» остаётся: движение не украшает, а **показывает
состояние** — уровень, маршрут, отклик на выбор. Вёрстка от анимации не
меняется. Токены — `src/lib/motion.ts`, примитивы — `src/components/motion/`.

Технические правила: только `transform`/`opacity` (и canvas карты), 60fps,
значения скролла — motion values без ре-рендеров React. Никаких `top`/`width`/
`height` в анимациях.

Разрешено:
- **фирменный индикатор бака** (`ScrollJourney`, без силуэтов машины/АЗС): тонкая шкала у правого края
  (десктоп) / полоса 3px сверху (мобайл), уровень = 1 − прогресс скролла,
  у дна страницы мягкий «долив» до полного (`tankRefillAt`, 1.1с);
- **маршрут**: когда адрес известен, на карте рисуется линия от ближайшей АЗС
  до машины клиента (`duration.route`, 0.9с);
- **отклик выбора**: заливка выбранного чипа перетекает к новому (`spring.chip`),
  press `scale(0.97–0.98)`;
- **тикер цифр** (`<Ticker>`): суммы, остатки с датчиков и цены набегают при
  первом появлении и перетекают при смене (`duration.ticker`, 0.6с);
- **карта АЗС**: точки на связи «дышат» (кольцо, своя фаза у каждой), у точки
  мини-шкала остатка — при наведении/тапе наливается до реального уровня;
- **линия шагов** «Как это работает», прорисовка по скроллу;
- **магнитный ховер** — только главный CTA, только десктоп с мышью, ≤6px;
- **появление блоков** (`<Reveal>`): 24px + opacity, 600мс, ease-out-quint,
  один раз, без стаггеров; hero не анимируется. Элемент всегда `motion.div`
  (SSR отдаёт opacity:0 — подмена на `div` оставила бы блок невидимым);
- шиты 200мс, направленные переходы шагов /benzin, skeleton-shimmer,
  pulse курьера на трекинге, CSS hover/press 150мс.

Запрещено: hero-стаггеры, каскады и задержки появлений, parallax, декоративные
бесконечные анимации (дыхание точек — статус «на связи», не декор), glow.

`prefers-reduced-motion`: всё статично — бак полный, шкалы и полосы на
реальном уровне, цифры сразу итоговые, маршрут рисуется целиком, секции на
месте, магнит выключен.

## 7. Компоненты — нормы

- **Выбор из 2–4 вариантов** (топливо, объём) — сегмент-контрол (§4). Внутренние
  экраны (/benzin, кабинет) пока на прежних чипах `rounded-control` — переводить
  на новый стиль по мере редизайна, не смешивая в одном экране.
- **Инпуты**: см. §4, ошибки — красный текст под полем.
- **Статусы**: цвет только у точки/бейджа. Бейджи — `rounded-md`, не пилюли.
- **Иконки**: lucide, тонкие (`strokeWidth` 1.6–1.75), `primary-700`/`navy`;
  без цветных подложек (исключение — круглые `white/10` на тёмной плитке).
- **Touch ≥44px**, focus-кольца видимы, контраст ≥4.5:1.

## 8. Definition of Done дизайн-PR

1. Скриншоты: все экраны × light+dark × мобайл+десктоп.
2. next-intl uz/ru/en, длины проверены.
3. Токены из `tailwind.config.ts`/`globals.css`/`src/lib/motion.ts` — без
   инлайн-значений.
4. Тёмная тема first-class (угольная), CI зелёный, backend не тронут.
