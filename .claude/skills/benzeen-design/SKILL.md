# Benzeen Design Doctrine

Benzeen привозит топливо к машине клиента в Ташкенте, 24/7. Интерфейс должен
внушать то же, что хороший сервис: **спокойную уверенность**. Не стартаперский
шум, а Apple-сдержанность: много воздуха, крупная уверенная типографика, один
акцентный цвет, мягкая глубина, физика пружин.

Проверка вкуса для любого экрана: *убери всё, что можно убрать; то, что
осталось, сделай безупречным.* Если элемент не помогает заказать топливо или
понять статус заказа — его быть не должно.

**REQUIRED BACKGROUND:** скилл `apple-design` (личный, `~/.claude/skills/`) —
физика движения, прерываемость, материалы. Этот скилл — конкретизация той
философии под Benzeen: точные значения токенов и запреты.

## 1. Цвет — один акцент, и только он

Палитра закрыта. **Новые цвета и оттенки не вводить** — только значения ниже.

| Роль | Значение | Использование |
| --- | --- | --- |
| **Кобальт (акцент)** | `#2E5BFF` | ЕДИНСТВЕННЫЙ акцент: primary-кнопки, активные состояния, ссылки, прогресс, выбранные чипы |
| Кобальт hover | `#2450E6` | hover primary-кнопок |
| Кобальт active | `#1D41C4` | active/pressed |
| Кобальт-тинты | `#F0F4FF` / `#DEE7FF` | подложки выбранного состояния, badge, светлые заливки |
| Кобальт в dark | `#6B8AFF` | акцент на тёмных поверхностях (контраст ≥4.5:1) |
| **Navy (текст/тёмное)** | `#13224F` | основной текст на светлом; базовый тон тёмных поверхностей |
| Neutrals | gray-шкала Tailwind | вторичный текст `gray-500/600`, бордеры `gray-200`, фоны `#F7F8FA` |
| Success | `#059669` | только успех (доставлено, оплачено) |
| Warning | `#D97706` | только предупреждения |
| Danger | `red-600` | только ошибки и разрушающие действия |

Правила:
- Один акцент на экран. Если кобальтом выделено больше одного смыслового
  фокуса — экран перегружен, убирай.
- Семантические цвета (success/warning/danger) — только для статусов, никогда
  для декора.
- Старые `petrol`, `amber-accent`, `glow`-тени — легаси, при рестайле удалять.
- Иконки — нейтральный `gray-500`/`navy`, НЕ красить каждую в кобальт и НЕ
  сажать каждую в цветной квадратик. Кобальтовая иконка = активное состояние.

## 2. Типографика — один гротеск, крупно и уверенно

Шрифт: **Inter** (уже подключён через `next/font`, `--font-inter`). Второго
шрифта нет. Вес: 400 текст, 500–600 UI-элементы, 700 только заголовки.

| Токен | Размер / межстрочный | Трекинг | Где |
| --- | --- | --- | --- |
| `display` | 44–56px / 1.05 | `-0.02em` | hero главной, один на страницу |
| `title` | 32–36px / 1.15 | `-0.02em` | заголовки страниц |
| `heading` | 24px / 1.25 | `-0.01em` | заголовки секций |
| `subheading` | 18px / 1.4 | `0` | подзаголовки, имена карточек |
| `body` | 16px / 1.5 | `0` | основной текст |
| `caption` | 13–14px / 1.4 | `0` | подписи, метки, hints |

- Крупный текст — тесный (отрицательный трекинг и низкий line-height); мелкий —
  свободный. Никогда один `letter-spacing` на всё.
- Иерархия — весом и размером, не цветом. Цифры сумм и объёмов —
  `font-variant-numeric: tabular-nums`.
- Заголовки — утверждения, не описания («Топливо приедет само», не «Наши
  услуги»). Тексты uz/ru/en — проверять длину на всех трёх.

## 3. Пространство — 8px-сетка, щедрый воздух

- Все отступы кратны 8 (4 допустимо внутри мелких элементов). Произвольных
  значений (`p-[13px]`) не существует.
- Контент: `max-w-[1200px]` центрирован; текстовые блоки `max-w-prose`.
- Секции лендинга: 96–128px вертикали на десктопе, 64–80 на мобайле. Между
  смысловыми блоками воздуха больше, чем внутри блока (закон близости).
- Плотность формы заказа: поля 48px высотой, 16–24px между группами.
- Если сомневаешься — добавь воздуха. Теснота = дешевизна.

## 4. Поверхности — мягкая глубина, без стекла

- Светлая тема: фон `#F7F8FA`, карточки `#FFFFFF` с бордером `gray-200/60` и
  мягкой двухслойной тенью (`shadow-soft`). Тень — намёк, не эффект.
- Радиусы: **12px** контролы/инпуты, **16px** карточки/панели, **20px** только
  нижние шиты. Кнопки — **pill** (`rounded-full`).
- `backdrop-blur` разрешён ТОЛЬКО в двух местах: шапка (`bg-white/85` +
  `backdrop-blur-md`) и нижние шиты (как в iOS). Больше нигде. Стеклянных
  карточек, блюр-подложек у секций и «вакханалии материалов» — нет.
- Никогда не класть светлую полупрозрачную поверхность на другую полупрозрачную.

## 5. Тёмная тема — первоклассная, не инверсия

- База — navy, не серый: фон `#0B1226`, поверхности `#141E3D` →
  приподнятые `#1B2749`. Иерархия глубины — светлотой поверхности, не тенями
  (тени в тёмной теме почти невидимы — вместо них бордеры `white/8`).
- Текст: `#F5F7FF` основной, `#8E9AC0` вторичный. Акцент — `#6B8AFF`
  (кобальт светлеет, иначе тонет).
- Чистый чёрный `#000` и чистый белый текст `#FFF` не использовать.
- Каждый новый компонент сдаётся сразу в двух темах; «потом докрасим» не бывает.

## 6. Motion — физика, не украшение

Источник констант: **`src/lib/motion.ts`** — все длительности/пружины импортом
оттуда, инлайн-значений в компонентах нет.

```ts
// src/lib/motion.ts — единственный источник motion-токенов
export const duration = { fast: 0.15, base: 0.2, slow: 0.3 } as const; // сек
export const easeOut = [0.25, 0.46, 0.45, 0.94] as const;
export const spring = {
  /** Дефолт UI: критически задемпфирован, без отскока */
  default: { type: 'spring', bounce: 0, duration: 0.35 },
  /** Нижние шиты и всё, что «бросили» жестом */
  sheet: { type: 'spring', bounce: 0.15, duration: 0.4 },
  /** Мелкий отклик: чипы, тумблеры */
  snappy: { type: 'spring', bounce: 0, duration: 0.25 },
} as const;
```

- Hover/focus/цвет — CSS-переходы `fast`/`base`. Появления и перемещения —
  `spring.default`. Отскок (`bounce > 0`) — только там, где был импульс жеста.
- Анимировать ТОЛЬКО `transform` и `opacity`. Не `height`, не `top`, не блюр.
- Вход элементов: fade + rise 8–16px, `ease-out`, стаггер 40–70ms. Выход — тем
  же путём (вошёл снизу — уходит вниз).
- Всё прерываемо: анимации не блокируют ввод, стартуют от текущего значения.
- `prefers-reduced-motion` → всё мгновенно: `MotionConfig reducedMotion="user"`
  + глобальный CSS-блок (уже в `globals.css`). Проверять при каждом motion-PR.

## 7. Компоненты — нормы

- **Кнопки**: pill; высоты 40 (sm) / 48 (md) / 52 (lg); primary — кобальт,
  secondary — `gray-100`/бордер, ghost — прозрачная. Press: `scale(0.97)`.
  На мобайле главное действие — фиксированная нижняя кнопка во всю ширину.
- **Инпуты**: 48px, радиус 12, бордер `gray-300`, focus — кобальтовое кольцо
  2px. Ошибка — красный бордер + текст под полем, инлайн, не по сабмиту.
- **Карточки**: белые, радиус 16, `shadow-soft`; hover — тень чуть глубже,
  без подпрыгиваний `-translate-y`.
- **Чипы выбора** (топливо, объём): pill, выбранный — кобальтовый тинт + бордер
  кобальт; невыбранный — `gray-100`. Переключение — `spring.snappy`.
- **Статусы заказа**: цвет только у точки/бейджа статуса, не у всей карточки.
- **Touch-таргеты** ≥44×44px. Фокус-кольца видимы всегда (`focus-visible`).
- **Иконки**: lucide, stroke 1.5–2, один размер в контексте (16/20/24).

## 8. Запреты — жёсткие

| Запрещено | Вместо этого |
| --- | --- |
| Градиентный шум, mesh-фоны, «переливы» | Чистый фон, один тинт-градиент максимум в hero и едва заметный |
| Неон, glow-тени (`shadow-glow-*`) | Мягкая нейтральная тень |
| Стоковые фото, 3D-рендеры, клипарт | Продуктовый визуал из настоящих UI-элементов |
| Бесконечные анимации (flow-lines, ping, pulse-декор) | Статика; движение только как ответ на действие или вход во вьюпорт (once) |
| Блюр где попало | Только шапка и нижние шиты |
| Второй акцентный цвет «для разнообразия» | Кобальт + нейтрали. Точка. |
| Анимация `height`/`width`/`filter` | `transform` + `opacity` |
| Хардкод цен/цифр в UI | Только из `/api/prices` и реальных данных |

Исключение живёт только как правка этого файла, не как «в этот раз можно».

## 9. Definition of Done дизайн-PR

1. Скриншоты: мобайл + десктоп × light + dark.
2. Все строки через next-intl (uz/ru/en), длины проверены.
3. `prefers-reduced-motion` проверен, если PR трогает motion.
4. Контраст текста ≥4.5:1, touch-таргеты ≥44px.
5. Токены — из `tailwind.config.ts` / `globals.css` / `src/lib/motion.ts`;
   новых инлайн-значений нет.
6. CI зелёный. Backend (`prisma/`, `/api`, auth, деньги) не тронут, если PR
   заявлен как фронтенд-пасс.
