# ТЗ v2 — Benzeen B2C («как Яндекс Такси»)

Собрано из интервью 20 вопросов, июль 2026. Заменяет B2B-витрину; B2B-код отключается и прячется, не удаляется.

---

## 0. Суть продукта

Консьюмерская платформа заправки авто в Ташкенте, 24/7, два раздела:

- **Бензин** — доставка топлива к машине клиента (SOS в дороге + плановая заправка у дома/офиса, оба сценария в v1).
- **Пропан** — заправка авто с ГБО на **точках**: газовозы Benzeen стоят на отмеченных на карте местах, клиенты подъезжают сами. Оборудование и разрешения есть — запускаем сразу.

Стиль: лёгкий, минималистичный, «яндексовский» — карта, одна кнопка, live-трекинг. Светлая тема + фирменный синий Benzeen. Языки: uz / ru / en (локали в коде уже есть).

Запуск: **один большой релиз**, весь Ташкент сразу.

---

## 1. Роли

| Роль | Что делает | Канал |
|---|---|---|
| Клиент | заказывает бензин / бронирует слот на пропан | сайт + PWA + обёртки в сторах |
| Курьер (бензин) | принимает автоназначенные заказы, шарит гео, возит | Telegram-бот (остаётся внутренним инструментом) |
| Оператор пропан-точки | отмечает обслуженные брони, статус точки | Telegram-бот или простой веб-экран |
| Админ | цены, курьеры, точки, заказы, отчёты | админка (текущая, вычищенная от B2B) |

---

## 2. Вход и регистрация

- Только **телефон + SMS-код** (+998, узбекский шлюз — **Eskiz.uz**; Twilio убираем).
- Никаких паролей для клиентов.
- **Машину спрашиваем при первом заказе** (госномер + марка), сохраняем в профиль.
- Кнопки «Войти / Регистрация» на минималистичном лендинге; после входа — сразу выбор раздела.

## 3. Главный экран

- Два раздела: **Бензин | Пропан** (финальные названия — открытый пункт, по умолчанию так).
- Ничего лишнего: логотип, переключатель языка, вход/профиль, два больших входа в разделы.
- Без демо-блоков, без маркетингового текста.

---

## 4. Флоу «Бензин» (доставка)

1. Карта на весь экран, пин = куда привезти: текущая геолокация / выбор на карте / **сохранённая локация (до 3 на пользователя: «Дом», «Работа»...)**.
2. Выбор топлива: АИ-92 / АИ-95 / АИ-100.
3. Объём: от **30 л** (минимум), пресеты + ручной ввод + «полный бак» (по объёму бака машины из профиля).
4. Цена: **как на АЗС** (маржа зашита в литр), **доставка бесплатно**. Цена и итог видны до заказа.
5. Оплата: **онлайн-предоплата (Payme / Click / Uzum)** или **терминал/QR у курьера**. Наличных нет.
6. Автоназначение **ближайшего свободного курьера по гео** (каскад: не ответил за N сек → следующий).
7. **Live-трекинг: курьер едет по карте + ETA «будет через N минут»** (маршрутизация через API карт).
8. Курьер заливает; клиент рядом и видит колонку — **подтверждение «Верно/Не верно» убрано**. Курьер фиксирует литры со счётчика, в истории клиента — чек.
9. Заказ в истории кабинета.

## 5. Флоу «Пропан» (точки)

1. Карта точек: где стоят газовозы, статус (работает/пауза), цена за литр СУГ.
2. Клиент может **встать в очередь, выбрав время** (слоты по 10–15 мин). Бронь = номер/QR.
3. Приехал к своему времени → оператор отметил «обслужен».
4. Работает 24/7 (как и доставка).
5. Оплата на точке: терминал/QR (онлайн-предоплата слота — можно этапом позже, отметить в UI «оплата на месте»).

---

## 6. Кабинет клиента

- История заказов (бензин) и броней (пропан).
- До **3 сохранённых геолокаций**.
- Машина/машины (номер, марка, объём бака).
- **Рефералка**: персональная ссылка/код.
  - Друг сделал первый **оплаченный** заказ → рефереру **+1 литр** (анти-фрод: начисление только после оплаты, не после регистрации).
  - Рубеж **10 друзей** → **+10 литров** бонусом к следующему заказу (поверх накопленных).
  - Литры-бонусы = скидка эквивалентом при следующем заказе.

---

## 7. Курьерская часть (бензин)

- Telegram-бот остаётся **только для курьеров**: приём автоназначенного заказа, навигация к точке (ссылка на карту — уже есть), ввод залитых литров со счётчика.
- Курьер **постоянно шарит live-геолокацию** (Telegram live location → уже есть механика relay) — на ней работают автоназначение и клиентский трекинг.
- Клиентский Mini App и клиентские функции бота — отключаются.

## 8. Админка

- Вычистить B2B (компании, лимиты, инвойсы) — **feature-флаг off, код не удалять**.
- Остаётся: заказы (B2C), курьеры + их статус/гео, **пропан-точки (создать/подвинуть/пауза, слоты)**, цены (АИ-92/95/100 + пропан), клиенты, отчёты за день/месяц, рефералка (начисления).

---

## 9. Мобилка

- База — тот же сайт (PWA уже заложен).
- **Обёртки в Play Market и App Store** (Capacitor): иконка, сплеш, пуш-уведомления (статусы заказа), геолокация.

## 10. Что отключаем (не удаляя)

- B2B-кабинеты компаний, модерация, лимиты по машинам, Invoice-модель, водительские аккаунты компаний.
- Клиентскую часть Telegram (Mini App заказа, диалог заказа в боте).
- Механику подтверждения «Верно/Не верно» (в B2C не нужна; код остаётся для будущего B2B).

## 11. Модель данных — изменения

- `User`: роль CLIENT; телефон — ключ входа.
- `ClientCar` (userId, plate, model, tankCapacity, fuelType) — создаётся при первом заказе.
- `SavedLocation` (userId, name, lat, lng) — максимум 3.
- `Order` (B2C): clientId, fuelType, volume | isFullTank, lat/lng/address, priceSnapshot, paymentMethod, paymentStatus, courierId, status, литры-факт, timestamps.
- `PropanePoint` (name, lat, lng, status, pricePerLiter).
- `PropaneBooking` (pointId, clientId, slotStart, status).
- `Referral` (userId, code, referredById) + `BonusLedger` (userId, liters, reason, orderId).
- `CourierLocation` (courierId, lat, lng, updatedAt).
- `Price`: + PROPANE.

## 12. Технические решения

- SMS: **Eskiz.uz** (замена Twilio в `verification.ts`).
- Карты + маршрутизация/ETA: **рекомендация — Яндекс Карты JS API** (лучшее покрытие Ташкента, роутинг из коробки; проверить стоимость коммерческой лицензии; запасной путь — MapLibre + OSM + OSRM бесплатно).
- Платёжки: Payme / Click / Uzum — вебхуки оплаты → статус заказа; **merchant-аккаунты оформляет Диор (оргзадача вне кода)**.
- Live-трекинг клиенту: SSE/поллинг `CourierLocation`.
- Пуши: web-push уже есть → переиспользовать в обёртках.

## 13. Внутренние этапы работ (релиз один, но строим по вехам)

- **M0 — прод-инфраструктура (блокер всего):** Neon/Postgres + env-переменные в Vercel + рабочий деплой. Без этого ни один этап не тестируется.
- **M1 — новая витрина и вход:** лендинг-минимализм, светлая тема, 3 языка, регистрация телефон+SMS (Eskiz), кабинет-скелет, B2B за флаг.
- **M2 — бензин-доставка:** карта, заказ от 30 л, цены, оплата (Payme первым, Click/Uzum следом), автоназначение, курьерский флоу в боте.
- **M3 — live-трекинг + ETA.**
- **M4 — пропан:** точки, карта, слоты/очередь, экран оператора.
- **M5 — рефералка + сохранённые локации + история.**
- **M6 — обёртки в сторы, полировка, нагрузочный прогон → релиз.**
